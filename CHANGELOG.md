# Changelog

Los cambios relevantes de AxiomLiquidityProtocol se documentan en este archivo.

## [1.0.0] - 2026-08-14

### Añadido

- Motor explícito de valoración para reportes de estrategia.
- Control plane con roles, pausas operativas y gobierno de límites.
- Modelo de estrés económico y reconciliación de NAV.
- Documentación de arquitectura, economía, operación, integración y seguridad.
- Gate reproducible con Bun, TypeScript, Prettier, tests e integridad de release.

### Cambiado

- Superficie pública y metadatos preparados para la primera versión estable.
- Automatización de dependencias y configuración de desarrollo normalizadas.
